# data-intelligence-app

A command-line data analysis application that accepts a CSV file, validates the input, analyzes the dataset, and generates a summary report and visualizations.

## Features

* Validates CSV file paths, file types, existence, and accessibility
* Validates the structure of the loaded dataset
* Loads CSV data using Pandas
* Reports the number of rows and columns
* Calculates total missing values
* Identifies numerical and categorical columns
* Generates descriptive statistics
* Generates missing-value visualizations
* Generates numerical-distribution visualizations
* Includes automated unit and integration tests using Pytest

## Architecture

The application follows a modular pipeline where each component is responsible for a specific task:

```text
CSV Input
   ↓
File Validation
   ↓
Load File
   ↓
Dataset Validation
   ↓
Data Analysis
   ↓
Report + Visualizations
```

### Responsibilities

* `validate.py` — validates the input file and dataset structure
* `load.py` — loads the CSV file into a Pandas DataFrame
* `analyze.py` — performs dataset analysis and prepares visualization data
* `visualize.py` — generates and saves visualizations
* `main.py` — orchestrates the application workflow and presents the report to the user

## Installation / Setup

Clone the repository and install the required Python dependencies:

```bash
pip install -r requirements.txt
```

## How to Run

Run the application from the project root:

```bash
python main.py
```

When prompted, enter the path to a CSV file.

For example:

```text
data/titanic.csv
```

The application will validate and analyze the dataset, display the analysis report, and generate visualizations in the `outputs/` directory.

## How to Run Tests

Run the test suite from the project root:

```bash
python -m pytest -q
```

The test suite includes unit tests for individual modules as well as an integration test for the complete data-processing pipeline.
